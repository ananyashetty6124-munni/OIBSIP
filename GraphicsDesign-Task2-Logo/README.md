# Task 2 – Logo Design

## Description

This folder contains logo designs created as part of the **OIBSIP Graphics Design Internship**.

The logo designs focus on creating a simple, recognizable, and professional visual identity using appropriate shapes, typography, and color combinations.

## Objective

The objective of this task is to design a minimalist and versatile logo that can effectively represent a brand or organization.

## Files

* `Ananya_Task2_Logo_FullColor.png` – Full-color logo
* `Ananya_Task2_Logo_Monochrome.png` – Monochrome logo
* `Ananya_Task2_Logo_Reversed.png` – Reversed logo

## Design Concept

The logo represents **PawNest**, a pet-related brand concept. The design uses a simple visual identity intended to communicate a friendly, caring, and trustworthy impression.

## Design Specifications

* **Design Style:** Minimalist
* **Logo Variations:** Full Color, Monochrome, and Reversed
* **Format:** PNG
* **Purpose:** Brand identity and visual representation
